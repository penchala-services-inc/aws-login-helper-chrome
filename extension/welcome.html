AWS Login Helper is installed

One more step before you can open isolated account/role windows.

Choose your OS:

Linux and ChromeOS aren't supported yet - the companion app is built for Windows and macOS only.

Windows

1

Install the companion app

A small, per-user Windows program does the actual work of opening each AWS account/role in its own isolated window - no admin rights needed, no UAC prompt. Download AWS-Login-Helper-Host-Chrome.msi from the latest release below and run it.

Download companion app (AWS-Login-Helper-Host-Chrome.msi)
2

Sign in and try it

Sign into your AWS IAM Identity Center (SSO / IIC) access portal as usual. Every account/role on your list will have an "Isolated (Window)" link next to it.

macOS

1

Download the companion app for your Mac

Pick the file that matches your Mac's chip. Not sure which? Open Terminal and run uname -m: arm64 means Apple Silicon (M1, M2, M3 and later), x86_64 means Intel.

Apple Silicon (arm64) Intel (x64)

Or grab it from the latest release page.

2

Extract it and run the installer

Open Terminal and run the commands for your Mac. The file is saved in Downloads by default.

Apple Silicon
cd ~/Downloads tar -xzf aws-login-helper-host-chrome-mac-osx-arm64.tar.gz cd osx-arm64 bash install.sh
Intel
cd ~/Downloads tar -xzf aws-login-helper-host-chrome-mac-osx-x64.tar.gz cd osx-x64 bash install.sh

The first run will be stopped by macOS - that's expected. The companion app is open source but isn't signed by Apple, so macOS asks you to approve it once. Keep going with the next step.

3

Allow the app in Privacy & Security

Open System Settings → Privacy & Security and scroll down to the Security section. You'll see "AWS-Login-Helper-Host-Chrome-Mac" was blocked to protect your Mac. Click Allow Anyway (enter your password or use Touch ID if asked).

4

Run the installer again and click Open Anyway

Back in the same Terminal folder, run it again:

bash install.sh

macOS now asks Open "AWS-Login-Helper-Host-Chrome-Mac"? - click Open Anyway. The installer then finishes and registers the app with Chrome.

5

Clear the download warning

Run this once in Terminal:

xattr -d com.apple.quarantine "$HOME/Library/Application Support/AWS-Login-Helper-Host-Chrome/NativeHost/AWS-Login-Helper-Host-Chrome-Mac"
6

Sign in, open an account/role, and allow it once more

Sign into your AWS IAM Identity Center (SSO / IIC) access portal as usual and click an "Isolated (Window)" link next to any account/role.

macOS will show one more Privacy & Security prompt, this time for the app installed in your home folder:

$HOME/Library/Application Support/AWS-Login-Helper-Host-Chrome/NativeHost/AWS-Login-Helper-Host-Chrome-Mac

Open System Settings → Privacy & Security, click Allow Anyway, then click the account/role link again.

That's it - you're all set. You won't be asked again.

Open source, nothing hidden

The companion app's entire source code is right there in this project's repo, under native-host/ (Windows) and native-host-mac/ (macOS) - it isn't a separate, closed-source download from somewhere else. All it does is launch a separate, dedicated Chrome window for each AWS account/role and copy your AWS SSO session cookie into it, so you don't have to sign in again. No telemetry, no data sent anywhere other than AWS itself.

You're welcome to read every line yourself before installing it: view the source on GitHub.

Already installed the companion app? Open the extension's options page and click "Check companion app" to confirm it's connected.
