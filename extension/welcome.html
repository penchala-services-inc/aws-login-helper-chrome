AWS Login Helper is installed

One more step before you can open isolated account/role windows.

1

Install the companion app

A small, per-user Windows program does the actual work of opening each AWS account/role in its own isolated window - no admin rights needed, no UAC prompt.

Download companion app
2

Sign in and try it

Sign into your AWS IAM Identity Center (SSO / IIC) access portal as usual. Every account/role on your list will have an "Isolated (Window)" link next to it.

Open source, nothing hidden

The companion app's entire source code is right there in this project's repo, under native-host/ - it isn't a separate, closed-source download from somewhere else. All it does is launch a separate, dedicated Chrome window for each AWS account/role and copy your AWS SSO session cookie into it, so you don't have to sign in again. No telemetry, no data sent anywhere other than AWS itself.

You're welcome to read every line yourself before installing it: view the source on GitHub.

Already installed the companion app? Open the extension's options page and click "Check companion app" to confirm it's connected.
